# Howler

**ES** — Howler guarda los tiempos de tu servidor de Assetto Corsa y los enseña en una web: clasificaciones, récords, fichas de piloto, comparador de vueltas y campeonatos. También controla el servidor desde un panel.

**EN** — Howler stores the lap times of your Assetto Corsa server and shows them on a website: standings, records, driver profiles, a lap comparer and championships. It also controls the server from a panel.

## Descargar / Download

Get `Howler-Setup.exe` from the [latest release](../../releases/latest) and check it against `SHA256SUMS`.

Windows may warn about an unknown publisher: the installer is not signed with a paid certificate. See the manual for how to check it is authentic.
