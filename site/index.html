    Everything it does

    Grouped by what you are trying to do.

    Timing and stats

    • Live standings with purple/green/yellow sectors and gaps
    • Exact sector times from the server plugin
    • Records per track and car, with ideal lap and weather
    • Session history and a page for every session
    • Driver, track and car profiles, head-to-head, rankings
    • King of the hill: every lap that lowered the session best
    • Live map with a vector track drawn from the game's own line
    • Telemetry for players with CSP: brake, throttle, G, tyres, ABS/TC

    Run the server

    • Start, stop, restart with a clean shutdown and live console
    • Full session panel with presets, fuel, damage, tyres, assists
    • Cars and track with Content Manager-style pickers
    • Scheduled events: weekly or one-off, race weekends, from a championship
    • Live control: time, weather, chat, kick, ban, ballast
    • Server sheet editor for how it looks in Content Manager
    • Startup diagnosis that explains why a server will not start
    • Accounts with admin, moderator and view-only roles for remote access

    Competition

    • Lap rules: cuts, collisions, minimum time, per track
    • Review queue for pit-exit laps and doubtful laps
    • Penalties: warnings, added time, disqualification, automatic rules
    • Championships: individual, pairs or teams, any scoring
    • Mod download links and car/track cards per race

    Connect and keep

    • Discord notices for records, sessions, events
    • MultiHowler: link several servers and share data
    • Import from stracker
    • Backups and CSV/JSON export
    • 6 themes, accent colour, drag-and-drop page layout
    • Spanish and English
    • Windows installer and a Linux package

    How it works

    Howler listens to the server, stores everything in a local database and serves the website. Nothing leaves your machine unless you link servers or set up Discord.

    Where the data comes from

    Server events and an optional plugin feed one local database.

    Player telemetry

    CSP clients send pedals, G and tyre data through a script the server hands out. Players install nothing.

    MultiHowler

    Peers share laps read-only; each lap is only ever edited by the Howler that recorded it.
